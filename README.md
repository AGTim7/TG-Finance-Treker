# FinanceTrackerBot

Адаптивное Telegram Mini App приложение и Telegram-бот для удобного учета личных финансов (доходов и расходов) с автоматическим расчетом баланса.

> 🔗 **Живое демо (Frontend):** https://financetrackerapp07.web.app/ *(Интерфейс оптимизирован под экраны мобильных устройств в Telegram).*
> 🤖 **Ссылка на бота:** https://t.me/financeOneTrackerBot/

---

## 🚧 Статус проекта: В активной разработке (Work in Progress)
На данный момент полностью спроектирована база данных, реализовано ядро бэкенда и пошаговые диалоги в Telegram-боте. Фронтенд Mini App находится на стадии верстки интерфейса и интеграции с API.

---

## 🛠 Технологический стек (на данный момент)

### Бэкенд (Telegram-бот)
* **Язык:** TypeScript
* **Фреймворк:** [grammY](https://grammy.dev/) (использование `@grammyjs/conversations` для линейных сценариев)
* **ORM:** Prisma
* **База данных:** PostgreSQL



### Фронтенд (Mini App)
* **Библиотеки:** React
* **Стилизация:** Tailwind CSS
* **Сборщик:** Vite / Create React App

## 💻 Локальное развертывание

### Привязка базы данных и окружения
1. Создайте файл `.env` в корне папки бота:
   ```env
   BOT_TOKEN=your_telegram_bot_token
   DATABASE_URL="postgresql://user:password@localhost:5432/finance_db?schema=public"

Вот аккуратно оформленный, чистый и структурированный вариант для вашего `README.md` файла. Я убрал лишние повторы команд Bash и выстроил всё в удобную для чтения структуру.

## 🚀 Запуск проекта

### 🤖 Бэкенд (Telegram Бот)

```bash
cd tgbot
npm install
npx prisma generate
npx prisma migrate dev
npm run build
npm start

```

### 📱 Фронтенд (Telegram Mini App)

```bash
cd tgapp
npm install
npm run dev

```
